# Precut architecture

The root pnpm application builds desktop code under `apps/desktop` and four shared workspace packages. The sandboxed renderer has no Node integration or filesystem/shell capability. All calls cross a context-isolated preload and a strict Zod method/payload whitelist in main; requests from another frame are rejected. File drops use Electron's File-to-path adapter and imports accept only supported media extensions. Media playback exposes UUID references through the `precut-media` protocol and serves ranges from a main-owned asset allowlist.

Projects retain source paths and sampled size/first/last-block fingerprints. Imported originals are not copied. Probe metadata includes rational frame rate, dimensions/rotation, stream codecs, duration and VFR indication. Derived audio, thumbnails, LOD waveforms, proxies, transcription checkpoints and export intermediates live under the app's project data folder.

SQLite runs in an isolated utility process with WAL, FULL synchronization, prepared statements, transactional command history and idempotent schema migrations. It stores media/tracks, transcript segments/words plus FTS, suggestions, caption settings, undo/redo commands, analysis state and export journals. Up to eight project connections are retained. Snapshots group words linearly rather than filtering the entire transcript for each segment. UI autosaves caption drafts and flushes them before an export; late saves do not switch the user back to a different project.

Each import, proxy, analysis, model download or export runs in its own utility process. Native processes use argument arrays with shell disabled, bounded stdout/error tails, cancellation and process-group termination. Native PID journals allow startup to stop orphaned sidecars only after verifying that their current command line matches both Precut's native path and that exact project. A stopped worker or app leaves saved edits available and interrupted jobs are marked recovered.

Analysis extracts 16 kHz mono PCM and runs Silero VAD, retaining its 32 ms speech probabilities. Silence confidence combines these probabilities with RMS relative to a local background noise floor and protected word boundaries. Conflicting evidence stays in Review. Balanced retains 425 ms of each pause. Fully silent recordings receive an explicit silence result while retaining the minimum preview/export duration.

Project speech preferences select Thai with English terms, English or Auto, with a vocabulary prompt and independent model quality. High keeps Large v3, GPU, beam 5 and DTW. VAD selects context windows around 20–28 seconds (maximum 30) with a one-second overlap and explicit word ownership. Auto chooses the primary language from representative windows. Thai-English keeps Thai as its default and uses the already installed Base model to confirm sustained English with multiple probes; mixed long passages split only at a VAD gap. Chinese/Hindi detections do not change the Thai profile. The selected transcription model loads once per job, including its one selective retry pass, through the patched native manifest protocol. This avoids command-line length limits on Windows. Base language classification uses a separate lightweight context.

The alignment module reads DTW centisecond anchors, refines boundaries against VAD, preserves Thai graphemes and joiners, and exposes timing source/confidence. Invalid timing falls back to token timestamps or Estimated; suspicious text/timing receives one context-expanded retry and unresolved results remain in Review. Runtime/model hashes, profile, prompt, segmentation and alignment versions identify transcription caches independently of cleanup pacing.

Analysis writes checkpoint files and SQLite staging rows. Only a successful final transaction replaces the visible transcript, FTS and caption cache. Cancel/crash preserves the old transcript and user corrections; an unfinished fresh pass leaves a durable marker so resume cannot accidentally reuse the old complete analysis. Accepted/kept/manual cuts and command-referenced pending cuts survive reanalysis. Explicit reassessment is required for previously kept silence. Auto Edit applies only newly generated high-confidence Silence/Pause proposals in one Undo command. Fillers, retakes and other semantic suggestions remain in Review.

The accepted-cut map quantizes to one rational frame grid and is reused by preview, captions and export. The playback clock drives Canvas directly while labels update at a lower rate. Static waveform/tick/cut rendering is separate from the playhead overlay. Transcript rows are virtualized and the workspace panels resize by mouse or keyboard. English/Thai UI strings and light/dark semantic tokens share the same views and locally bundled fonts.

Six caption presets share data, word grouping, layout and animation code between browser Canvas and worker Skia. Karaoke uses time-progressive word reveal; highlighting/pop follow word times. Captions remap after cuts and the last subtitle is clamped to output duration. Original-source MP4 export stages frame-count-controlled CFR MOV parts with PCM audio, concatenates them, encodes H.264/AAC and optionally composites bounded RGBA overlay frames. The same operation can publish an SRT sidecar. NLE exports use FCPXML 1.10 or FCP7 XML, correct source ranges and external-audio availability/offset ranges; VFR footage receives persistent CFR compatibility media.

The SDK boundary is independent of editing. Signed vendor verification precedes installation/build; production exports require actual PC configuration and `runWithAccess`. Artifact receipts and main journals drive conservative quota recovery. Native update downloads are verified before the user chooses to open an installer. Support diagnostics contain version/platform/job outcome codes and licence mode; they exclude transcript text, media paths and licence secrets.

Engineering verification and release limits are documented in `QA.md`. Current heuristic cleanup is deliberately conservative; it is not a guarantee that an artistic or semantically intentional repetition is removable. Optional local multilingual E5 suggestions stay in review. Accuracy, very long natural recordings, all destination editors and live store policy need acceptance on representative production material.
