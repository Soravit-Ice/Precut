# Precut 2.1.0

- Download, import, Auto Edit, manual editing, preview and project saving are free. MP4, subtitle and editor exports require an activated paid licence with export access.
- Windows speech processing selects compatible CPU acceleration at runtime, including AVX2 where supported, and uses a bounded CPU thread budget. Selected speech quality and word alignment settings are preserved.
- Windows Settings accurately describes CPU acceleration. Diagnostics include effective speech mode, CPU threads and time spent in each processing stage.
- Older pending trial exports can still be reconciled after the Store export quota is set to zero. Keep the Store free trial/download setting enabled for downloads and recovery.
- Pushing a matching version tag now starts the full Windows and Mac release pipeline, including packaged application acceptance and Store checksum verification submission.

Deploy the Store zero-quota support and save Precut's trial export quota as 0. Keep `trialEnabled: true` in the SDK configuration. Store verification and publication are separate steps. Performance varies with CPU, selected speech model and recording length.
