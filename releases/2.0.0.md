# Precut 2.0.0

- จัดการ Recent projects ได้จากปุ่มลบที่มองเห็นชัด พร้อม Undo และคืนโปรเจกต์จากรายการที่นำออก
- แก้บทพูดด้วย Edit text: คลิกคำเพื่อแก้ พิมพ์แล้วกด Enter พร้อมฟังเสียงประกอบ
- เพิ่ม Find & replace พร้อมตัวอย่างการเปลี่ยนคำ และ Undo การแทนที่ทั้งหมดในครั้งเดียว
- Caption studio แสดงตัวอย่างสไตล์แบบเคลื่อนไหวและบนวิดีโอจริง ปรับสีข้อความและคำที่กำลังพูดด้วยชุดสีหรือ HEX ได้
- Auto Edit แสดง progress ทันที พร้อม 5 ขั้นตอน เปอร์เซ็นต์จากงานจริง เวลาใช้ไป และแถบเคลื่อนไหวระหว่างประมวลผล
- ทำงานต่อเบื้องหลังแล้วเปิดดู progress ได้ พร้อมสถานะเมื่อเสร็จ ยกเลิก หรือเกิดข้อผิดพลาด
- ปรับระยะโลโก้มุมซ้ายบน และนำ CK ออกจากตัวอย่างชื่อและศัพท์เฉพาะ
- ปรับการกู้คืนงานส่งออกและการตรวจสิทธิ์จาก Store

ตัวติดตั้งสำหรับ macOS Apple Silicon (ARM64), Mac Intel (X64) และ Windows (X64) จะส่งเข้า Store เมื่อทุกระบบผ่านการ build และทดสอบแอปที่แพ็กจริงใน GitHub Actions
Apple Silicon ต้องใช้ macOS 27 ขึ้นไป; Mac Intel ต้องใช้ macOS 15 ขึ้นไป
ตัวติดตั้งยังไม่ลง publisher signature และยังไม่ notarize การอัปเดตให้ดาวน์โหลดและติดตั้งจาก Store
ใช้บัญชี สิทธิ์ และที่เก็บโปรเจกต์เดิม
