# Precut 1.0.1

- เพิ่มตัวติดตั้ง macOS Intel (x64) แยกจาก Apple Silicon (ARM64)
- เพิ่มตัวติดตั้ง Windows (x64)
- รวมตัวติดตั้งทั้ง 3 ระบบใน release เดียว ตรวจ checksum ฝั่ง Store ก่อนเผยแพร่
- ใช้ชื่อแอป, บัญชี, licensing และที่เก็บโปรเจกต์เดิม

Apple Silicon ต้องใช้ macOS 27 ขึ้นไป; Intel ต้องใช้ macOS 15 ขึ้นไป
ตัวติดตั้งยังไม่ลง publisher signature และยังไม่ notarize การอัปเดตให้ดาวน์โหลดและติดตั้งเองจาก Store
