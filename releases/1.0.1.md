# Precut 1.0.1

- รุ่นนี้มีตัวติดตั้งสำหรับ macOS Apple Silicon (ARM64) และ Mac Intel (X64)
- ปรับการใช้ CPU ของระบบวิเคราะห์เสียงบน Apple Silicon ให้เหมาะกับจำนวน core ของเครื่อง
- ตรวจไฟล์จริงและ checksum ฝั่ง Store ก่อนเผยแพร่
- ใช้ชื่อแอป, บัญชี, licensing และที่เก็บโปรเจกต์เดิม

Apple Silicon ต้องใช้ macOS 27 ขึ้นไป; Mac Intel ต้องใช้ macOS 15 ขึ้นไป
Mac Intel ใช้ไฟล์จาก build ที่ทดสอบผ่านแล้วของ source fa0a15fc7173727c6bdf181e49aa04d664b44c35 โดยตรวจ SHA-256 กับ manifest เดิม ไม่มีการเริ่ม hosted CI ใหม่
Windows ยังไม่รวมในรุ่นนี้ เพราะการวิเคราะห์เสียงยังรอผลทดสอบบน Windows ก่อนเผยแพร่
ตัวติดตั้งยังไม่ลง publisher signature และยังไม่ notarize การอัปเดตให้ดาวน์โหลดและติดตั้งเองจาก Store
