# Precut 1.0.1

- รุ่นนี้เผยแพร่สำหรับ macOS Apple Silicon (ARM64)
- ปรับการใช้ CPU ของระบบวิเคราะห์เสียงให้เหมาะกับจำนวน core ของเครื่อง
- ตรวจไฟล์จริงและ checksum ฝั่ง Store ก่อนเผยแพร่
- ใช้ชื่อแอป, บัญชี, licensing และที่เก็บโปรเจกต์เดิม

Apple Silicon ต้องใช้ macOS 27 ขึ้นไป
ตัวติดตั้ง Mac Intel และ Windows ยังไม่รวมในรุ่นที่เผยแพร่นี้ ต้องทดสอบและเผยแพร่แยกในเวอร์ชันถัดไป
ตัวติดตั้งยังไม่ลง publisher signature และยังไม่ notarize การอัปเดตให้ดาวน์โหลดและติดตั้งเองจาก Store
