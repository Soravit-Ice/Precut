# Precut 2.0.1

- Download, import, Auto Edit, manual editing, preview and project saving remain free. MP4, subtitle and editor exports require an activated paid licence with export access.
- Windows speech processing selects compatible CPU acceleration at runtime, including AVX2 where supported, and uses a bounded CPU thread budget. Speech quality and word alignment settings are preserved.
- Windows Settings accurately describes CPU acceleration. Export diagnostics include effective speech settings and time spent in each processing stage.
- Older pending trial exports can still be reconciled after the Store export quota is set to zero. Keep the Store free trial/download setting enabled for downloads and recovery.

The Store must deploy zero-quota support and save Precut's trial export quota as 0. Performance varies with CPU, selected speech model and recording length.
