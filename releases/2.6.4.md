# Precut 2.6.4

- Add Subtitle Animation Studio with 17 original HyperFrames designs, six existing presets, searchable style previews and Thai/English support.
- Apply styles to the whole clip or an individual caption, preview changes on the source video and keep Undo/Redo, grouping and translations intact.
- Render animated MP4 captions locally with bundled fonts, textures, emoji and a pinned offline browser. SRT exports retain ordinary text and timestamps.
- Preserve original template typography and colors, allow explicit customization and restore the original design.
- Improve font and settings dropdown placement, scrolling and keyboard selection in light and dark themes.
- Wait for browser and encoder cleanup before completing or cancelling an export, and recover interrupted caption workers after restart.

- Make clean CI installation use the explicitly pinned caption browser instead of running Puppeteer's separate browser download hook.

- Preserve vendored resource bytes across Git checkouts so integrity verification is identical on macOS and Windows.

- Validate original caption fidelity against native export frames on each OS, with unchanged pixel-difference limits and separate poster integrity checks.

Downloads, editing, preview and project storage remain free. Exports retain production license enforcement. Unsigned installers use manual installation and updates; platform support follows the native acceptance results for this release. Apple Silicon requires macOS 27 or later; Intel requires macOS 15 or later.
