# Precut 1.0.0

First stable desktop build. Made by t2etech.

- Local media import, speech analysis, non-destructive editing, captions and guarded exports.
- T2ETECH account connection, purchase activation and server-verified trial export access.
- Bundled Fast speech/VAD models and native tools; no separate Node, Python or FFmpeg installation.
- Updates for unsigned installers are downloaded from the Precut Store page and installed manually.

Initial prepared target: macOS Apple Silicon (ARM64). Windows x64 and macOS Intel require their own approved native inputs, build and acceptance run before offering downloads.
