# Precut 2.5.0

- ปรับปรุงระบบ Caption workspace: รองรับการลากวางตำแหน่งแคปชันบนวิดีโอโดยตรง (Drag & drop), ตัวช่วยจัดกึ่งกลาง (Center snapping), ปรับละเอียดด้วยปุ่มลูกศร (1px / Shift 10px), ปรับตำแหน่งรายข้อความหรือทั้งโปรเจกต์ และรองรับ Undo/Redo
- ระบบแปลภาษาแคปชันแบบออฟไลน์ (Offline AI Translation): เลือกภาษาไทย, อังกฤษ, หรือแปลสองภาษา (Thai + English) ใน Auto Edit โดยประมวลผลผ่านโมเดลในเครื่องโดยตรง ไม่ส่งข้อมูลออกนอกเครื่อง
- รองรับฟอนต์ข้อความรวม 44 ฟอนต์ (24 ฟอนต์ภาษาไทย และ 20 ฟอนต์ภาษาอังกฤษ) พร้อมระบบตรวจสอบสัญญาอนุญาต OFL และรองรับการนำเข้าฟอนต์ภายนอก (TTF/OTF) เข้าสู่โปรเจกต์
- ปรับปรุงความแม่นยำของ Safe cuts: ตัดเฉพาะช่วงเงียบ/หยุดพูดที่มีความมั่นใจสูงและรักษาระยะความปลอดภัยของเสียงพูดอย่างน้อย 80 ms พร้อมคงคำฟุ่มเฟือยและคำพูดซ้ำให้ผู้ใช้เลือก Review เอง
- ตัวติดตั้งรองรับทั้ง macOS Apple Silicon (ARM64), macOS Intel (x64) และ Windows (x64) พร้อมระบบทดสอบ Packaged Application Smoke Test และการส่งข้อมูลยืนยันไปยัง Store

การดาวน์โหลด, ตัดต่อ, พรีวิว และบันทึกโปรเจกต์ใช้งานได้ฟรี การส่งออกไฟล์วิดีโอ MP4, แคปชัน และโปรเจกต์ตัดต่อต้องใช้ไลเซนส์ที่เปิดใช้งานแล้ว
